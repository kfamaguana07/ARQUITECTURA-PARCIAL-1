EurekaBank REST API

Especificación e información técnica de los servicios web del sistema bancario.

Ruta Base (Context Path): /api/eurekabank
POST /api/eurekabank/login

Autentica las credenciales de un empleado del banco.

Body (JSON):
{
  "usuario": "Monster",
  "contrasena": "Monster9"
}
Respuesta (200 OK):
{
  "codigo": 1,
  "mensaje": "Login exitoso"
}
GET /api/eurekabank/cuentas

Obtiene la lista de todas las cuentas bancarias activas junto con la información de sus titulares.

Respuesta (200 OK):
[
  {
    "codigo": "00100009",
    "nombreCliente": "Monster",
    "saldo": 9999.00,
    "estado": "ACTIVO",
    "moneda": "01",
    "emailCliente": "monster@monster.edu.ec",
    "telefonoCliente": "0999999999"
  }
]
GET /api/eurekabank/movimientos?cuenta={codigo}

Consulta los movimientos registrados para una cuenta en específico.

Query Parameters:
  • cuenta (opcional): Código de la cuenta bancaria (ej: 00100009).
Respuesta (200 OK):
[
  {
    "codigoCuenta": "00100009",
    "numero": 1,
    "fecha": "2026-10-28",
    "tipo": "Apertura Entrada",
    "importe": 9999.00,
    "referencia": null,
    "saldoActual": 9999.00,
    "nombreCliente": "Monster"
  }
]
POST /api/eurekabank/movimientos

Registra un nuevo movimiento bancario (Depósito, Retiro o Transferencia).

Body (JSON) - Ejemplo Transferencia:
{
  "cuentaOrigen": "00100009",
  "cuentaDestino": "00100002",
  "tipo": "TRANSFERENCIA",
  "importe": 900.00
}
Respuesta (200 OK):
{
  "codigo": 1,
  "mensaje": "Operación exitosa"
}
GET /api/eurekabank/tipos

Devuelve el catálogo de tipos de movimientos permitidos por la aplicación.

Respuesta (200 OK):
[
  "DEPOSITO",
  "RETIRO",
  "TRANSFERENCIA"
]
